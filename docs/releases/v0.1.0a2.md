# AVID 0.1.0a2 (alpha)

**Pre-release. Not production-ready. Not validated with live trading.** Real trading stays off by
default. Read [KNOWN_ISSUES.md](../../KNOWN_ISSUES.md) and the
[release readiness report](../audits/RELEASE_READINESS.md) first.

This release prepares AVID for open source: one consistent command line after `pip install`, an
offline simulator, a time-bounded controlled stop that reports what it really did, fixes from the
pre-release audit, and a complete documentation and CI set.

## Highlights

* `avid-engine simulate --example btc-usdt` runs the real engine on stored synthetic prices, offline.
* `avid-agent install | start | stop | restart | uninstall | logs` work from a pip install; `stop`
  exits 3 or 4 when the cancellation of the bot's orders was not confirmed.
* Fixed: a broken `cryptography` install no longer crashes the engine (PRA-03); a full disk no longer
  disables STOP (PRA-09); the pure-Python signer is refused for live mainnet orders (PRA-04).
* Human-readable output and `--json`; severity on every log event; pre-trade risk checks reported.

## Breaking changes

* The pure-Python signer override (`AVID_ALLOW_PURE_ED25519=1`) is honoured only on the official testnet.
* `avid-agent status` is human-readable; use `--json` for the JSON.
* Service `TimeoutStopSec` is 300 s; containers need `stop_grace_period: 300s`.
* Documents moved: `docs/AGENT_PROTOCOL.md`, `docs/SECURITY_ARCHITECTURE.md`, `docs/STRATEGY_MATH.md`,
  `docs/audits/`.

Full list: [CHANGELOG.md](../../CHANGELOG.md). Findings and their status:
[PRE_RELEASE_AUDIT.md](../audits/PRE_RELEASE_AUDIT.md).

## Verify the download

```bash
sha256sum -c SHA256SUMS
gh attestation verify avid_rebalancer-0.1.0a2-py3-none-any.whl --repo mshamsk138/avid   # releases built by the workflow
```

The SBOM (`avid-rebalancer-0.1.0a2.cdx.json`, CycloneDX 1.5) lists the package, its optional
`cryptography` dependency and the pinned build and test dependencies. AVID has no runtime dependencies.
