# Code of conduct

This project adopts the **Contributor Covenant, version 2.1**
(<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>) as its code of conduct, for every
project space: issues, pull requests, discussions and any other channel the project uses.

In short: be respectful and constructive, assume good faith, criticise ideas and code rather than
people, and do not harass anyone. Sharing someone's private information (including exchange account
details, API keys or balances) without permission is never acceptable.
