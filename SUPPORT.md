# Support

AVID is an alpha maintained on a best-effort basis. There is no paid support and no guaranteed response
time.

| you need | go to |
|---|---|
| install or usage help | [docs/INSTALLATION.md](docs/INSTALLATION.md), [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md), then a GitHub issue ("Bug report" or a question) |
| a bug | a GitHub issue with the **Bug report** form |
| a feature | a GitHub issue with the **Feature request** form - read [docs/ROADMAP.md](docs/ROADMAP.md) first |
| a documentation problem | the **Documentation** form |
| a vulnerability, an unwanted order, a stop that did not stop, a wrong financial record | **not** a public issue: [SECURITY.md](SECURITY.md) |
| your Nobitex account, deposits, withdrawals | Nobitex support - AVID cannot see or change your account |
| AVID Cloud (the hosted dashboard) | the operator of that service; it is not part of this repository |

Before posting anything public, remove API keys, the agent key, account identifiers, balances and order
ids. Logs can contain all of these.
